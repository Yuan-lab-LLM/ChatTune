# medflow/tests/data

This directory contains functional-test fixtures for MedFlow request handlers and benchmark-style workflows.

Data policy for open-source releases:

- Fixtures in this directory must be synthetic or de-identified before publication.
- They are intended only for development, regression tests, and API-shape examples.
- They must not be treated as real clinical records, medical advice, or representative evaluation data.
- Maintainers must remove or replace any file whose provenance cannot be verified as synthetic or properly de-identified.
- Do not add names, phone numbers, ID numbers, addresses, hospital numbers, or other direct personal identifiers.

The audio samples are test media for speech-related code paths only and must not contain identifiable speaker information.
